# Как продолжать в новом чате

1. Прочитай `FRONTEND_ARCHITECTURE_GUIDE.md` (целиком при первой работе, далее — §12).
2. Прочитай `docs/session-context/CURRENT.md`, затем `PLAN.md`.
3. Не пересобирай каркас и не рефакторь готовые части без задачи.
4. Делай **одну** следующую сессию из `PLAN.md`.
5. В конце: обнови `CURRENT.md`, статусы в `PLAN.md`, добавь `sessions/NNN-slug.md`. Пауза.

Запуск фронта: `npm install` в корне, затем `npm run dev` (открыть http://localhost:5173).
