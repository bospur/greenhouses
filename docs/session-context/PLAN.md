## Структура монорепы

```
Greenhouses/
├── FRONTEND_ARCHITECTURE_GUIDE.md   # стандарт фронта (§12 — контекст этого проекта)
├── package.json                     # npm workspaces (apps/web)
├── apps/
│   ├── web/                         # Vite + React 19 + TS (профиль spa-app)
│   └── api/                         # Go 1.26 — появляется в фазе B
├── docs/
│   ├── session-context/             # PLAN / CURRENT / sessions
│   └── adr/                         # архитектурные решения
├── proto.html, proto_v2_dark 3D.html  # исходные HTML-прототипы (референс)
└── docker-compose.yml               # фаза B (api + postgres)
```

## Дизайн-направление («среднее» между прототипами)

- Светлая основа из `proto.html`: каталог, карточка, формы, чертежи — читаемо.
- Из `proto_v2_dark 3D.html`: тёмный hero с CSS-3D теплицей, бейдж, trust-bar,
  scroll-reveal, нумерованные шаги конфигуратора, тёмный футер.

  тёмная тема включается `data-theme="dark"` (позже — переключатель).

## Фаза B — Go API (`apps/api`)

| # | Сессия | Содержание | Статус |
|---|--------|-----------|--------|
| B1 | Каркас API | Go-модуль, `chi`, конфиг из env, логгер `slog`, healthcheck, CORS, OpenAPI-контракт (`api/openapi.yaml`), Postgres + миграции (`goose`), docker-compose | ⬜ |
| B2 | Каталог + цена | `GET /products`, `GET /products/:slug`, `POST /pricing/quote` — **серверный расчёт цены** (источник истины; фронт считает только превью) | ⬜ |
| B3 | Доставка | интерфейс `DeliveryProvider` + адаптеры: СДЭК API v2 (calculator/tariffs), Деловые Линии, ПЭК, Почта (по наличию договоров); `GET /delivery/cities?q=`, `POST /delivery/quotes`; кеш котировок; таймауты/частичные ответы | ⬜ |
| B4 | Заказы + ЮKassa | `POST /orders` (пересчёт цены и доставки на сервере), подтверждение телефона (SMS-код, опц.), `POST /orders/:id/payment` → ЮKassa (СБП QR / redirect), webhook `POST /webhooks/yookassa` с проверкой, статусы заказа, idempotency-key | ⬜ |
| B5 | Уведомления + админ-минимум | уведомление менеджеру (Telegram/email), чек 54-ФЗ через ЮKassa, простая выдача заказов (защищённый endpoint / позже админка) | ⬜ |

## Открытые вопросы к заказчику

1. Какие ТК реально подключены (есть ли договоры/ключи СДЭК, ДЛ, ПЭК)? Откуда отгрузка (город склада)?
2. Формула цены своей теплицы: за м², за секцию (шаг дуг 0,65/1 м?), форма (арка / капля / домик)?
3. Нужно ли подтверждение телефона SMS-кодом или достаточно звонка менеджера?
4. Юрлица: счёт на оплату нужен в MVP?
5. Монтаж: фиксированная цена или зависит от региона/размера?
6. Название бренда/домена (в прототипах — «ТеплицаПро»).
7. Вес и габариты упаковки по моделям (для расчёта ТК); сейчас груз оценивается формулой в `checkout/domain/cargo.ts`.
