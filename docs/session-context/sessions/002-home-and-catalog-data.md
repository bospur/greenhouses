# Сессия 002 — A2 главная + данные каталога

- Дата: 2026-11-16
- Цель: слой данных каталога на моках и полноценная главная страница.

## Результат

- Цепочка `catalogSource (mock | axios) → CatalogRepository → useProductsQuery / useProductQuery`.
- 6 моделей в моках (3 популярные), формы: арка, капля, домик.
- Главная: тёмный Hero с CSS-3D арочной теплицей, TrustBar, Features, PopularProducts, HowItWorks, DeliveryBlock, CtaBanner.
- SVG-иллюстрация теплицы по реальным размерам вместо фото-заглушек в карточках.
