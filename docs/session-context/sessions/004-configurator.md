# Сессия 004 — A4 конфигуратор

- Дата: 2026-11-16
- Цель: `/configurator` — параметры теплицы, ограничения, превью цены, живой чертёж, переход в заказ.

## Результат

- `/configurator`: 4 нумерованных шага (форма и размеры → каркас и покрытие → двери и форточки → дополнительно)
  и итоговая карточка «Ваша теплица» (параметры, разбивка цены, «Перейти к оформлению»).
- Справа — «липкий» чертёж в трёх видах (спереди + сбоку, ниже сверху) в общем масштабе и строка «Итого / В заказ».
  На ≤960 px чертёж встаёт после шага 1, внизу фиксированная панель «Итого / В заказ».
- `?from=slug` — предзаполнение из модели каталога, плашка «За основу взята модель…» и «Вернуть параметры модели».
  Неизвестный slug / ошибка — пояснение и базовая конфигурация.
- Автоподстройка с пояснением у шага: смена формы подрезает ширину/высоту, широкая/длинная теплица, 8 мм или «домик»
  усиливают каркас, лимит форточек по длине, термопривод снимается при 0 форточек. Недопустимые каркасы заблокированы
  с причиной; у вариантов показана доплата с учётом автоподстройки.
- «В заказ» → `/checkout?shape=drop&w=3&l=5&h=2.4&frame=40x20&poly=4&doors=2&vents=2[&opt=…]`.
- Чертёж каталога получил вид сбоку и форточки (две на торцах над дверью, остальные на скатах поочерёдно);
  карточка модели тоже показывает форточки.
- Проверено в браузере: 1024 и 390, lint / typecheck / build — зелёные.

## Решения по ходу

- Формула цены — заглушка (вопрос №2 к заказчику): ставка за м² по форме × коэффициент высоты + доплата за каркас
  (за пог. м) + поликарбонат (за м²) + вторая дверь / доп. форточки + опции; округление вверх до 100 ₽.
  Откалибрована по «Классик» (24 800 ₽ против 24 900 ₽ в каталоге); остальные моки каталога с ней не согласованы.
- RHF хранит значения, все правки идут через `update(step, patch)` → `normalizeConfig` → `form.reset(…, { keepDefaultValues })`:
  зависимые поля меняются атомарно, без `useEffect`. Zod `configSchema` проверяет и при submit.
- `configShapeSchema` (только типы) для разбора URL — выход за ограничения не отбрасывает конфигурацию, а нормализует.
- Предзаполнение: форма монтируется с `key` по slug и `defaultValues` из модели — без синхронизации в эффекте.
- `ProductDrawing` — prop `rows`: ширина строки пропорциональна содержимому, масштаб общий; на мобильном виды
  стопкой с `max-height: 200px`.
- Cross-module импорт `configurator → catalog` зафиксирован в ADR-003.
- Новое в shared: `Stepper` (−/+), `formatPriceDelta`; маршрут `APP_ROUTES.checkout.withConfig`.
- Бандл > 500 kB (добавились zod + RHF) — lazy-роуты в A6.
