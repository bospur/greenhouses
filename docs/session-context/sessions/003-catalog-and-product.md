# Сессия 003 — A3 каталог + карточка модели

- Дата: 2026-11-16
- Цель: страница каталога с фильтрами и страница модели (галерея, табы, чертёж, 404).

## Результат

- `/catalog`: `CatalogGrid` — фильтры «форма / ширина / цена до» и сортировка, всё состояние в URL
  (`?shape=arch&width=3&price_max=30000&sort=price-asc`), счётчик результатов, сброс, пустое состояние с CTA в конфигуратор.
- `/catalog/:slug`: `ProductDetails` — хлебные крошки, галерея (схема + фото-плейсхолдеры), цена/скидка/наличие,
  «Заказать» → `/checkout?product=slug`, «Изменить размеры» → `/configurator?from=slug`;
  табы «Характеристики / Чертёж / Комплектация / Фото»; клик по фото во вкладке открывает его в галерее.
- `ProductDrawing`: SVG «вид спереди (торец) + вид сверху» в общем масштабе, размерные линии с засечками,
  осевые, пунктир дуг, двери на торцах.
- 404 для неизвестного slug — дружелюбный экран внутри `ProductDetails` (без повторных запросов).
- `<title>` страниц через React 19 (каталог, модель, 404).
- Проверено в браузере: 1024 и 390, lint / typecheck / build — зелёные.

## Решения по ходу

- Фильтрация и сортировка — на клиенте (6–20 моделей). При росте каталога перенести в `ProductsQueryParams` и API (B2).
- `NotFoundError` в `shared/utils`: репозиторий переводит `MockNotFoundError` и HTTP 404 в него;
  `useProductQuery` не ретраит 404. Feature не знает о source/axios.
- `useProductQuery` берёт `placeholderData` из кеша списка — карточка из каталога открывается мгновенно.
- Контур торца вынесен в `domain/profile.ts` (`profilePath`, `getSectionCount`) — общий для иллюстрации и чертежа,
  конфигуратор (A4) может строить свой чертёж на `buildProductDrawing` или тех же примитивах.
- Новые shared UI: `Tabs` (ARIA tablist, стрелки/Home/End), `Breadcrumbs`; утилита `pluralize`.
