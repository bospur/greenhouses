# ADR-002: Zustand для черновика заказа и конфигуратора

- Status: accepted
- Date: 2026-11-16

## Context

Выбранная теплица (стандартная или своя конфигурация) должна переживать переходы
между страницами (каталог → конфигуратор → оформление) и перезагрузку страницы.

## Decision

- `orderDraft` — Zustand store с `persist` (localStorage): `item` (стандартная модель
  или конфигурация), без цен с API.
- Значения формы конфигуратора — react-hook-form; при «В заказ» результат кладётся
  в `orderDraft`.
- Котировки доставки, каталог, статус заказа — только React Query.

## Consequences

- Нет дублирования серверных данных в store (GUIDE §6.2).
- При изменении схемы конфигурации нужна версия persist-стора (`version` + `migrate`).
