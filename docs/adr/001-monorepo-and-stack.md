# ADR-001: Монорепа и стек

- Status: accepted
- Date: 2026-11-16

## Context

Сайт продажи теплиц: каталог, конфигуратор с чертежом, оформление заказа с расчётом
доставки через API транспортных компаний и оплатой через ЮKassa. Нужен собственный
бэкенд (секреты ТК и ЮKassa, серверный пересчёт цены, webhooks).

## Decision

- Монорепа: `apps/web` (React) + `apps/api` (Go). JS-часть — npm workspaces
  (pnpm не установлен, npm достаточно для одного JS-пакета).
- Web: Vite + React 19 + TS, React Router 7, TanStack Query 5, react-hook-form + Zod,
  Zustand (черновик заказа, persist), CSS Modules + CSS variables. Без Tailwind и UI-кита.
- Профиль GUIDE: `spa-app`. До появления API `data/source` возвращает моки
  (переключение по `VITE_API_URL`), остальные слои — как в боевом режиме.
- API: Go + chi + Postgres. Контракт — OpenAPI, источник типов для фронта.
- Цена и стоимость доставки **пересчитываются на сервере** при создании заказа;
  фронтовый расчёт — только превью.

## Consequences

- Фронт можно разрабатывать и показывать без бэкенда.
- Формула цены дублируется (TS-превью и Go-источник истины) — покрыть общими
  тест-кейсами (таблица вход → цена) в фазе B2.
